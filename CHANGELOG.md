# Changelog

## 1.0.0

First release.

- Commute time by public transport, steps and an interactive map on every idealista listing, and a sort-by-commute entry in idealista's own *Ordenar* list
- Runs against your own server, or entirely in the browser with your own Google Routes key and OpenStreetMap
- Optional fake-photo check with Sightengine, per result card or on the listing page
- Spanish by default, English when the browser is in English
- API keys are encrypted with a passphrase and unlocked from the toolbar popup once per browser session
